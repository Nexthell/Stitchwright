# Stitchwright

Lettering, monogram and SVG embroidery software for Windows, by CF Design (Norway).
Exports PES, DST, JEF, EXP, VP3 and XXX.

**Early preview.** This is a hobby project in active development. Stitch results may not match the preview, so always test-stitch on scrap fabric first.

## Download
Get `Stitchwright.exe` from the [Releases](../../releases) page. Windows 10/11, 64-bit.
If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
